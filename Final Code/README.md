## ✨ Project Overview

DevRoot is your go-to hub for building meaningful connections, sharing knowledge, and working on exciting projects. With a focus on security, real-time communication, and a developer-centric experience, DevRoot offers:

- **Encrypted real-time chat**
- **Intelligent developer matchmaking**
- **Verified profiles and trust signals**
- **Comprehensive user and connection management**
- **Admin and moderator controls**
- **Weekly email reminders and notifications**
- **Modern, responsive UI with React and Tailwind CSS**

---

## 🖥️ Frontend Features

- **Modern UI/UX**: Built with React, Tailwind CSS, and Framer Motion for a seamless, responsive experience.
- **Authentication**: Secure signup, login, and session management.
- **Profile Management**: Edit, view, and customize your developer profile, including skills, bio, and more.
- **Real-Time Chat**: Encrypted messaging with online status, typing indicators, and unread message notifications (Socket.io).
- **Connection Requests**: Send, accept, reject, or ignore connection requests.
- **Network Visualization**: View your connections, followers, and following lists.
- **Search**: Find developers by name, username, or skills.
- **Admin Dashboard**: Role-based access for admins and moderators to manage users and requests.
- **Notifications**: In-app and email notifications for important events.
- **Premium Membership**: Upgrade to premium for enhanced features (future scope).

---

## 🛠️ Backend Features

- **RESTful API**: Built with Node.js, Express, and MongoDB (Mongoose).
- **Authentication & Authorization**: JWT-based auth, role-based access (admin, moderator, user).
- **User & Profile Management**: CRUD operations for users, roles, and statuses.
- **Connection System**: Robust logic for sending, accepting, ignoring, and deleting connection requests.
- **Encrypted Chat**: AES-256 encrypted chat messages, real-time delivery via Socket.io.
- **Email Integration**: AWS SES for transactional and reminder emails (weekly cron jobs).
- **Admin & Moderator Tools**: APIs for user management, statistics, and moderation.
- **Statistics & Analytics**: Endpoints for tracking user and request statistics.
- **Scalable Architecture**: Modular codebase, environment-based configuration, and future-ready endpoints (posts, projects, etc.).
